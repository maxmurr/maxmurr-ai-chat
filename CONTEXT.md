# AI Chat

A workspace-based AI chat app: users sign in with email OTP, belong to workspaces, and hold persisted conversations with an AI assistant that can be shared with teammates or via public link.

## Language

**Chat**:
A single linear conversation between one user and the assistant — an append-only sequence of Messages. Owned by exactly one User (its creator, forever) and scoped to exactly one Workspace. May belong to at most one Project; the owner can attach or detach it at any time.
_Avoid_: Conversation, thread, session

**Message**:
One turn in a Chat, from either the user or the assistant. Stored as the full AI SDK UIMessage (parts: text, reasoning, tool calls, files, sources), never as plain text.

**Workspace**:
The team container users belong to and chat within. Backed by Better Auth's `organization` table — "organization" is the storage name only.
_Avoid_: Organization, team, org

**Owner (of a Chat)**:
The User who created the Chat. The only person who can append Messages to it, rename it, change its Visibility, or delete it. Ownership never transfers.

**Visibility**:
Who can see a Chat: `private` (owner only), `workspace` (all members of the Chat's Workspace, read-only), or `public` (anyone with the Public Link, read-only). Viewing never grants writing.
_Avoid_: Access level, sharing mode

**Public Link**:
An unguessable token URL granting live read-only access to a Chat's current state. Revocable; deleting the Chat kills it.
_Avoid_: Share link, snapshot

**Title**:
A Chat's display name. Auto-generated once by a cheap model after the first exchange; owner can rename.

**Library**:
A User's private collection of Files and Folders, scoped to one Workspace. Only the owning User ever sees their Library — nothing in it is shared with teammates.
_Avoid_: Drive, documents, storage

**File (Library)**:
One uploaded or chat-originated document, image, or code/text file in a Library. Owned forever by the User who uploaded it (or whose Chat produced it). Lives at the Library root or inside exactly one Folder. Duplicate names are allowed — identity is the id, the name is a label.
_Avoid_: Asset, attachment, blob, upload

**Folder**:
A flat, single-level grouping of Files inside a Library. Folders never nest. Deleting a Folder deletes the Files inside it.
_Avoid_: Directory, collection

**Project**:
A named, owner-private grouping of Chats under one Custom Instructions text. Owned by one User, scoped to one Workspace, addressed by id. Its files live in an ordinary Folder in the owner's Library (see Project Folder). Deleting a Project deletes its Chats; its Folder and Files survive. Teammates and Chat viewers never see a Project or its contents.
_Avoid_: Workspace, folder (as a synonym), collection

**Custom Instructions**:
The single free-text directive on a Project, applied to the assistant in every Chat belonging to that Project. Empty means no effect.
_Avoid_: System prompt, prompt

**Project Folder**:
The Folder in the owner's Library where a Project's Sources live. Created lazily on the first Source, named after the Project at that moment, and never renamed or deleted by the Project afterward — it is an ordinary Folder the user may manage freely. If deleted, the next Source recreates it.

**Source**:
A File that lives in a Project's Folder — uploaded on the Project page, moved there from the Library, or uploaded within one of the Project's Chats. Sources organize files; they are not sent to the model.
_Avoid_: Project file, attachment, reference

**Provenance (of a File)**:
The Chat and Message a File came from, when it entered the Library via chat — either attached by the user or generated by the assistant. Manual uploads have none. Deleting a File leaves a placeholder where the Chat referenced it; deleting never blocks on Provenance.
_Avoid_: Source, origin link
